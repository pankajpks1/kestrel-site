A property can hold a list instead of a single value — the tags on an article, the categories a user picked, or the items in a shopping cart. Kestrel understands two kinds:

  • Lists of values, such as ["Shoes", "Bags"].
  • Lists of objects, where each item has its own keys, such as a cart: [{"name": "Shoes", "price": 40}, {"name": "Bags", "price": 25}].

Send them from your app as a JSON array; no setup is needed.

Breaking down by a list

A breakdown by a list counts each item separately. An event whose list is ["Shoes", "Bags"] appears in both the Shoes and the Bags segments, so the segments can add up to more than the total. For a list of objects, pick the key to break down by — for example the cart items' name.

  • An empty list of values ([]) appears as (empty list); an empty list of objects has no keys to show and appears as (not set).
  • An event without the property appears as (not set).

Filtering on a list

  • Any in List keeps events where at least one item matches.
  • All in List keeps events where every item matches. An empty list never counts as "all".

With a list of objects you also choose what is counted: Include All Items keeps every item of a matching event, while Include Matching Items keeps only the items that match. For example, to measure revenue from shoes alone in carts that also hold other things, filter the cart's name to Shoes with Include Matching Items.

Measuring a list

Each list also offers computed values you can filter, break down or aggregate like any number property:

  • Size — how many items the list holds.
  • Sum — the total of a number key across the items (for example the cart's total price).
  • Distinct Count — how many different values a key takes across the items.

When aggregating an item's number, items where it is text, empty or missing are skipped, not counted as zero.

In Funnels and Retention

A funnel or retention report broken down by a list puts each person in a segment for every distinct item of their event, so one person can appear in several segments.
