Every metric in an Insights report has a Measuring menu below it. It decides what the number on the chart means: how many people, how many events, or a calculation over a property's values. All measurements are exact counts over your data.

Unique Users

The number of distinct people who did the event in each interval. A person who did it ten times on Monday counts once for Monday.

The ⚙ settings next to it choose how users are aggregated:

Aggregate byWhat it shows
Interval (Default)Distinct users in each chart interval (each day, week, month…).
Daily Active UsersDistinct users per day. Day interval only.
Weekly Active UsersDistinct users in the 7 days ending on each point. Day or Week interval.
Monthly Active UsersDistinct users in the 30 days ending on each point. Day, Week or Month interval.
Cumulative UsersDistinct users from the start of the range up to each point. Line chart only.

With a breakdown, Count Unique Users decides where a person who appears in several segments is counted: in Every Segment (the default), only in the First Segment, or only in the Last Segment they appeared in.

Total Events

The number of times the event happened. Duplicate events with the same insert ID are counted once.

Total Sessions

The number of sessions in which the event happened, using your project's session settings.

Frequency per User

How many times each person did the event, then summarised across people: Distribution (how many people did it once, twice, three times…), Average, Median, a Percentile (25th, 75th, 90th, or any level you enter), Minimum or Maximum.

Aggregate Property

A calculation over a number property across every matching event: Sum, Average, Median, Distinct Count, a Percentile (25th, 75th, 90th, 99th or any level), Minimum or Maximum. For example, the Sum of amount on Order Completed is your revenue.

Events where the property is missing, empty or not a number are skipped — they are not counted as zero.

Aggregate Property per User

Two steps: first each person's own value (Sum, Average, Distinct Count, Minimum or Maximum of the property), then a summary across people (Average, Sum, Distribution, Median, Percentile, Minimum or Maximum). For example, "Average of (Sum amount)" is the average spend per paying user.

Calculation options

Under Advanced, a line or column chart can show a Rolling Average over 7, 14 or 28 days, or a Cumulative Sum that adds each interval to the ones before it.
