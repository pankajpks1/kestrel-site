A computed property isn't stored on your events. Kestrel works it out from each user's history at the moment you run a report. Find them under Computed in the property picker of a Breakdown or a Filter in Insights and Funnels. (To build a new property from a formula over existing ones, see Custom properties.)

Computed properties always use exact counts and respect the data view you're in. Merged identities count as one user. They aren't available in reports on groups.

First Seen

First Seen is the time of a user's first event ever — any event, across all of their history. Break down by it to group users by when they first arrived, or filter to users who first appeared in a given period.

Behavioral properties

Behavioral properties describe what a user did with a given event. Both are worked out per interval: on a line chart, once for each interval (day, week and so on); in a bar, table, metric or funnel, once over the report's whole date range.

Frequency per User

How many times each user did an event. Choose Frequency per User…, then pick the event. Breaking down by it gives a segment for each count — "0 times", "1 time", "2 times" and so on. A user who didn't do the event in the interval counts as 0 times.

Aggregate Property per User

A value computed from an event's property for each user. Choose Aggregate Property per User…, then:

  1. Choose how to aggregate: Sum, Average, Distinct Count, Minimum or Maximum.
  2. Pick the event.
  3. Pick the property.

For example, break down by the Sum of amount on Purchase to compare users by how much they spent. A user with no value for the property in the interval has no value (it shows as not set) rather than 0.

Using them

  • In a Breakdown, they behave like any other property, and you can group their values with Customize Buckets.
  • In a Filter, pick the computed property and set a condition, for example Frequency per User of Checkout equals 3.
