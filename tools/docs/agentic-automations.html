An automation watches one metric for you. On the schedule you choose, it works out how the metric moved, writes a short digest — a summary, key findings and next steps — and delivers it to your email or Slack channels. Today the type available is the KPI Monitor.

Create one

  1. Choose Create New › Automation, pick the type and give it a name. It starts as a Draft.
  2. On the Configuration tab set the trigger, the metric, the analysis and the delivery (below).
  3. Choose Save & Activate. An automation needs a name and a valid metric before it can be activated.

Trigger: the schedule

Schedules run in the project's time zone, at a time you set (09:00 by default).

RepeatsOptions
DailyChoose which weekdays it runs on.
WeeklyOne weekday, every 1 to 12 weeks. Weeks start on your project's first day of the week.
MonthlyA day of the month (the 31st runs on the last day of shorter months) or the first, second, third, fourth or last given weekday, every 1 to 12 months.

"Every N weeks" and "every N months" count from the week or month you activated the automation.

Metric and analysis

  • Metric — an event metric as in Insights, with filters: event count, unique users, sessions, or the sum, average, median, minimum, maximum or distinct count of a property.
  • Breakdown (optional) — one property. The digest then lists the top 5 and bottom 5 segments.
  • Instructions (optional, up to 4,000 characters) — tell the digest what to focus on or how to word it. Instructions shape the commentary only; they never change the numbers.
  • Analysis window — how many complete days each run looks at. It depends on the schedule, and changing the schedule resets it to the first option.
ScheduleWindow options (days)
Daily7 (default), 14, 21
Weekly30 (default), 60, 90
Monthly90 (default), 180, 365

What a digest contains

Each run compares the metric over the window with the equally long window just before it. The numbers are exact — unique users are counted once across the whole window, not added up from daily counts. The digest points out:

  • the window moving 10% or more against the window before;
  • the last day sitting 2 or more standard deviations from the window's daily average;
  • the window's highest or lowest day.

The commentary may only quote numbers Kestrel computed. If it quotes any other number, that version is discarded and a plain version built from the computed facts is sent instead.

Delivery

Add up to 50 email addresses and up to 20 Slack channels. With none, the digest appears only on the automation's page. Each run also appears there with its result.

Running and managing

  • Run Now starts a run immediately on an active automation. The page shows Running… until it finishes.
  • The overview shows the status (Draft, Active or Paused) and the next run.
  • Delete Content removes the automation.

Limits

  • Up to 20 automations per person in a project.
  • Digests always show the top 5 and bottom 5 segments.
