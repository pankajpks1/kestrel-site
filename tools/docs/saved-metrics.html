When a team agrees on how something is measured — "weekly active buyers", "sign-up to first order conversion" — save it once so everyone uses the same definition. Kestrel keeps two kinds:

  • Metrics: reusable measurements built from events, including formulas.
  • Behaviors: reusable funnel or retention definitions, which you can use as a metric in other reports.

Both are listed under Lexicon › Metrics and Behaviors.

Saving one

  1. Build the metric in a report.
  2. Open its ⋮ menu and choose Save Metric (or Save Behavior).
  3. Check the name and add a description, then save. Names must be unique.

A report using a saved metric stays linked to it. If you change the metric inside a report, its ⋮ menu offers Push Changes (update the saved metric for everyone), Save as New, or Clear Changes.

Editing

In Lexicon, a metric's side panel edits its description, number format (prefix, suffix, abbreviation, decimals) and preferred direction — whether up is good or bad. These changes apply at once to every report that uses the metric. Edit opens the metric's definition in a new Insights report.

Deleting

Choose Delete on the metric's page, or select several and use Bulk Actions › Delete. Saved reports that use a deleted metric may stop working.
