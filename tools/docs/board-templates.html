A board template is a ready-made board of reports for a common question — how a feature launch is going, where an online store loses buyers. You tell the template which of your events and properties to use, and it builds every report from them.

Adding your events

Picking a template opens a Draft board with a Set Up Board panel beside it. Each line in the panel asks a question — "What is your product's core value moment?" — and you answer it by choosing one of your events or properties. The draft redraws as you go, so you can see each report take shape.

Templates ask for events rather than guessing them because every product names things differently: your Order Completed might be someone else's Purchase or checkout_success. Mapping them once means every report on the board measures what you actually track.

When every required line is filled, Save builds the board. You can edit any of its reports afterwards like any other report.

The Ecommerce template

The Ecommerce board follows the path from browsing to buying: product views, add-to-cart, purchases, revenue by category, and how new visitors convert. It needs both events and properties:

  • Sign Up and Product Viewed events.
  • Purchase, with its cart property and each item's price.
  • Add to Cart, with its cart property and each item's category.
  • Optionally, your ad data event and its cost property, for marketing spend.

The cart must be a list of objects — one object per item, each with keys such as price and category — so the board can count items, sum their prices and break revenue down by category. The panel's Need help setting up this template? card walks through each step.
