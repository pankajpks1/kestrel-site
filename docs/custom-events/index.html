Custom events

Combine or filter existing events into one event you can use in any report.

A custom event is an event you define in Kestrel from events you already track. Use one when several events mean the same thing to you — Signed Up with Google and Signed Up with Email as one Sign Up — or when you want only some occurrences of an event, such as Order Completed where amount is over 1,000.

Custom events work on all your history straight away and appear in every report's event picker.

Creating one

  1. Go to Lexicon › Custom Events and choose + Create Custom Event, or pick + Create New in a report's event picker.
  2. Give it a Name.
  3. Under Match my custom event when any of the following events happen, add the events. Each one can have its own filters on event properties or user properties.
  4. Save. A new custom event is private to you until you share it.

How it counts

  • An event is counted when it matches any of the listed events (with their filters).
  • An event that matches two of the entries is still counted once.
  • User-property filters use each person's current profile.

Editing and deleting

Open the custom event in Lexicon and choose Edit. Changes apply to every report that uses it. Delete is inside Edit; reports that used a deleted custom event will show an error until you replace it.
