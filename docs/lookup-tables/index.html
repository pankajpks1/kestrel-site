Lookup tables

Upload a CSV to add extra details to a property's values — product IDs to names, plan codes to prices.

A lookup table is a CSV file you upload to enrich a property. If your events carry a product_id, a table that maps each ID to its name, category and price lets you filter and break down by those columns as if your app had sent them — on all your history, with no code change.

Preparing the CSV

product_id,name,category,price
p-101,Running Shoes,Footwear,40
p-102,Tote Bag,Bags,25
  • The first column is the key. It is matched against the property's values exactly, including upper / lower case and spaces.
  • The first row is the header and must name every column; names can't be empty or repeated.
  • Every row must have the same number of fields, and keys must be unique. Rows with an empty key are skipped.
  • Use UTF-8. Quoted fields, line breaks inside quotes and Windows line endings are fine.
  • Each column's type (text, number, true / false or date) is taken from the most common kind of value in it.
  • A file can be up to 100 MB. A project's lookup tables can hold up to 5,000,000 rows in total.

Uploading and mapping

  1. Go to Lexicon › Lookup Tables and choose Import Lookup Table.
  2. Choose the CSV, and optionally pick the property to Map to.
  3. Save. The table's columns now appear under the mapped property in every property picker.

You can also map or unmap later: in Lexicon, select event or profile properties and use Bulk Actions › Map To Lookup Table or Unmap From Lookup Table. A property maps to one table at a time.

Values with no matching row, and empty cells, appear as (not set).

Trying a table in one report

In a report, open a breakdown's ⋮ menu › Map Lookup Table, then pick an existing table or import a CSV. Apply maps it for that report only, so you can try a table without changing it for everyone.

Updating and deleting

Open a table to Export it, Replace it with a new CSV (reports pick up the new version straight away), or Delete it.

Who can do what

  • Uploading a table needs the Analyst role or higher.
  • Mapping a table to a property in Lexicon needs Admin.
  • An Owner can replace, delete or describe any table; an Admin can do so for the tables they uploaded.
