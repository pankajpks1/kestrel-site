Custom buckets

Group a breakdown's values into ranges or named groups, automatically or your own way.

Breaking a report down by a property with many values — prices, durations, ages — gives one segment per value, which is hard to read. Buckets group those values into ranges (for numbers) or named groups (for text), so the report shows a handful of meaningful segments.

Automatic buckets for numbers

When you break down by a number property and haven't set buckets yourself:

  • With 23 or fewer distinct values, each value gets its own segment.
  • With 24 or more, Kestrel groups the values into equal-width ranges such as 0 - <20, 20 - <40 … >= 240. The width is a round number (1, 2 or 5 times a power of ten) chosen so that about a dozen ranges cover most values; anything above the top range goes into the last, open-ended one.
  • Values that aren't numbers appear as (non-numeric values).

Setting your own number buckets

Open the breakdown's ⋮ menu › Customize Buckets and choose a tab:

TabWhat it does
EvenEqual-sized ranges. Set Min, Max and Size — for example 0, 100 and 10 gives <0, 0 - <10, 10 - <20 … ≥100. If Max isn't a whole number of sizes above Min, the last range runs on to the next one: 0, 35 and 10 ends with 30 - <40 and ≥40. Up to 1,000 ranges.
VariedRanges of your choosing. Enter the boundaries, in any order (they're sorted when you leave a box) and each only once — for example 0 and 2 gives <0, 0 - <2, >=2.
NoneNo grouping: one segment per value.

Choose Apply. If something is missing or out of range, a note above the editor says what, and Apply waits until it's fixed. Reset returns to the automatic buckets.

Grouping text values

For a text property, Bucket by… lets you build named groups: each group lists the values it contains (Is …, Else Is …), and Else remaining values collects everything you haven't listed into one group.

Grouping dates

For a date property, choose the unit each segment covers — from an hour up to a year.
