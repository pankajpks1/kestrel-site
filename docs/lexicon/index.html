Lexicon

Your project's data dictionary: every event and property you track, what it means, and how it appears in reports.

Lexicon lists everything your project tracks and lets you document and tidy it, so everyone picking an event in a report knows what it means.

What's listed

PageWhat it holds
EventsActions users take in your product that you track in Kestrel, with their 30-day volume and how often they are queried.
Event PropertiesDetails attached to events that you filter and break down by, with an example value and the events that carry each one.
Profile PropertiesAttributes on user profiles, with how many users have each one.

Lexicon also holds what you build on top of your data: custom events, custom properties, metrics and behaviors, lookup tables and cohorts.

Search matches an entry's name or display name. Filters narrow the list by status, owner, tags, verification, and whether an entry is one of yours or one Kestrel tracks automatically.

Documenting an entry

Select an entry to open its side panel. Admins can set a display name (shown in reports instead of the raw name), a description, tags, platforms, owners and an image.

Bulk actions

Select entries with their checkboxes, then open Bulk Actions:

ActionWhat it doesRole
Hide / Make VisibleHides an entry from report pickers. Data still arrives and nothing is lost; you can undo it at any time.Admin
Merge / UnmergeTreats two or more events or properties as one in reports — useful when the same thing was tracked under different names.Owner
Block / UnblockStops new data for an entry from being processed. It can take a few hours to take effect, and blocked data cannot be recovered.Owner
Mark ClassifiedMarks a property as sensitive. Only people who have been granted Classified Data Access can see its values, and reports that use it are locked for everyone else.Admin
Map To / Unmap From Lookup TableConnects a property to a lookup table.Admin

Exporting

Export CSV downloads the rows you are looking at — after search and filters — with the columns currently shown.
