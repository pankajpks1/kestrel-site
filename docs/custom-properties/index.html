Custom properties

Build new properties from formulas over the ones you already track — no code change, applied to all your history.

A custom property is a property you define with a formula instead of sending it from your app. It is computed when a report runs, so it works on all your existing data straight away, and changing the formula changes every report that uses it.

Typical uses: cleaning up messy values, grouping many values into a few, pulling a domain out of a URL, or combining two properties into one.

Creating one

  1. In any report's property picker (a filter or a breakdown), choose + Create New › Custom Property. You can also start from Lexicon › Custom Event Properties or Custom Profile Properties.
  2. Give it a Name and write the Formula. Type a period (.) to insert a property, and press Ctrl + Space to list the functions. Insert Example fills in a ready-made formula to start from.
  3. Choose Apply to use it in this report only, or Save to keep it. A saved custom property is private to you until you share it.

Examples

In these examples, utm_source, current_url and signup_date stand for properties you insert by typing a period.

// Group traffic sources into channels
IFS(
  HAS_PREFIX(utm_source, "google"), "Search",
  utm_source IN ["facebook", "instagram"], "Social",
  TRUE, "Other"
)
// The domain of a URL
PARSE_URL(current_url, "domain")
// Days since the user signed up
DATEDIF(signup_date, TODAY(), "D")

Functions

KindFunctions
LogicIF, IFS, AND, OR, NOT, IN, DEFINED, TRUE, FALSE, UNDEFINED, LET
TextLEFT, RIGHT, MID, LEN, LOWER, UPPER, HAS_PREFIX, HAS_SUFFIX, SPLIT, REGEX_EXTRACT, REGEX_MATCH, REGEX_REPLACE, PARSE_URL
NumbersCEIL, FLOOR, ROUND, MIN, MAX
DatesTODAY, DATEDIF (units "Y", "M", "D", "YM", "YD", "MD")
TypesBOOLEAN, NUMBER, STRING, TYPEOF
ListsANY, ALL, MAP, FILTER, SUM

IN, HAS_PREFIX and HAS_SUFFIX ignore upper and lower case.

Operators

  • Compare with = (or ==), !=, <, >, <=, >=.
  • Calculate with +, -, *, /, %. Adding two pieces of text joins them. Dividing by zero gives an undefined value rather than an error.
  • Write lists in square brackets: ["a", "b"]. Start a comment with //.

Data type

The result's type — text, number, true / false, date or list — comes from the formula's outermost operation. You can change how a breakdown treats it from the breakdown's ⋮ menu › Data Type.

Limits

A formula can be up to 20,000 characters long, and a description up to 10,000.
